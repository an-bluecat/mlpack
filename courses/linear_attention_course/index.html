Linear attention, from the matrices to the memory

Six lessons, one worked example, an executed PyTorch lab.

The one idea

Replace a visit to every past token with a read from a small table of accumulated key-value information. You gain efficient long-context computation and give up direct access to the individual history. This course derives both sides of that tradeoff.

Start after ordinary attention and KV caching. You need matrix multiplication and basic PyTorch; every new operation in the lab is demonstrated before the complete function.

  1. 1. Where the quadratic cost comes from

    Start with the dimensions in your notes. Separate a full sequence from one cached decode step.

  2. 2. Change the rule, then move the parentheses

    One three-token example proves what is preserved and what is changed.

  3. 3. Why ELU+1 and a denominator?

    Separate positive features, normalized weights, and LayerNorm. They solve different problems.

  4. 4. A causal attention layer is a recurrent memory

    Use only the prefix. Write the current token, read the current state, then continue.

  5. 5. Backward, then the complete implementation

    Follow a last-token loss into earlier values. Then verify the assembled code against an independent reference.

  6. 6. What the small memory forgets

    Compression explains both the efficiency and the limitations. Then gates and delta updates have a reason to exist.

Learn by running the same example

Reference implementations and verification include bidirectional, recurrent and chunked forms, with dense-reference, gradient, causality and streaming checks.
