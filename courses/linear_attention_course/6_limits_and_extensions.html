6. What the small memory forgets

Compression explains both the efficiency and the limitations. Then gates and delta updates have a reason to exist.

Two histories, one state

A collision you can calculate

two stored keys both have features [1,1] history A values: [2,0], [6,0] history B values: [0,0], [8,0] both give S = [[8,0],[8,0]] and z = [2,2] query features [1,1] gives [16,0]/4 = [4,0]

Once only S and z remain, every future read of this bare memory is identical for the two histories. The state does not remember which token supplied which part of the total. Later queries cannot reconstruct that distinction from these summaries alone.

Put the limitation in the right place

Identical keys also prevent a content-only softmax query from distinguishing those tokens. The example proves information loss in the summary, not a universal softmax victory. A softmax KV cache retains the individual vectors, which can support later operations requiring token identity; a fixed summary has already combined them.

Refresher: is the whole causal attention matrix rank ≤ M?

The unmasked matrix U Aᵀ has rank at most M, and row normalization preserves that bound when denominators are nonzero. A causal triangular mask can increase rank: with M=1 and all features 1, the normalized causal matrix has diagonal 1,1/2,…,1/T and full rank. “Every causal linear attention matrix has rank ≤ M” is false.

Why random features enter the picture

softmax similarity before row normalization: exp(q·k / sqrt(Dk)) choose random features ψ so their dot product approximates that exponential similarity

The approximation permits the same summary/read pattern. More features cost more memory and work; approximation accuracy and numerical stability matter. ELU+1 is simpler but does not have that specific target. See Choromanski et al., Rethinking Attention with Performers.

Forgetting and correcting

A forget gate makes older writes fade

simplified scalar-gated normalized memory: S_t = g_t S_(t−1) + a_t v_tᵀ z_t = g_t z_(t−1) + a_t 0 ≤ g_t ≤ 1

A gate g_t=1 keeps the past; g_t=0 clears it before this write. Repeated gates multiply an old write’s influence. We apply the same gate to z here so the normalized-weight interpretation remains consistent. This is a teaching variant; GLA uses richer data-dependent gating and a different full architecture. See Yang et al., Gated Linear Attention.

A delta update writes the prediction error

S orientation stays (key width, value width) predicted = S_old.T @ k error = v − predicted S_new = S_old + β k error.T

Instead of adding the full value every time, correct what the memory currently predicts at this key. For a unit-length key k and β=1, the read at k becomes v after the update.

k=[1,0], stored row=[2,0], new v=[6,0], β=1 additive write: [2,0]+[6,0] = [8,0] delta write: [2,0]+([6,0]−[2,0]) = [6,0]

This unit-key delta example is a separate memory rule, not our positive normalized ELU+1 algorithm. Do not copy its denominator or feature assumptions blindly. DeltaNet adds machinery to train such updates efficiently; see Yang et al., Parallelizing Linear Transformers with the Delta Rule.

Refresher: does correcting one key leave all other keys unchanged?

Only keys orthogonal to the write direction are unaffected. A different key with a nonzero dot product with k can see the update too. The delta rule improves the write policy; it does not create unlimited independent storage.

Read papers and finish the course

A reading order with one question per paper

  1. Katharopoulos et al. (2020), Transformers are RNNs — how do a normalized feature kernel and recurrence correspond?
  2. Choromanski et al., Rethinking Attention with Performers — what would it take to approximate softmax rather than choose another kernel?
  3. Dao et al. (2022), FlashAttention — why can reducing memory traffic beat a better asymptotic count at practical shapes?
  4. Yang et al., Gated Linear Attention — how do chunking and input-dependent forgetting help?
  5. Yang et al., Parallelizing Linear Transformers with the Delta Rule — how do you correct stored associations and parallelize training?

These are foundational readings, not a claim to survey every architecture available in 2026.

What about positions and masks?

Unmasked summary attention is unchanged if you jointly permute the key/value rows. Causal order and gates introduce order sensitivity. Positional information can be included in Q/K features, but arbitrary pair-dependent positional biases or masks need not factor into a fixed-size summary. Do not drop an arbitrary softmax mask or standard RoPE recipe into this normalized positive kernel and assume every property survives.
